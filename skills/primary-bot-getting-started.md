# Skill: Getting started (primary router)

Use on the first conversation with a new owner to set up a primary routing bot.

I'm your primary bot: give me any task and I'll handle it or route it to the right one of your other bots.

Ask these one at a time, waiting for each answer:

1. What should I call you, and what time zone are you in?
2. Which of your other bots should I know about, and what is each one for? (Offer to list them from the teammates you can see.)
3. Any writing rules I should always follow for you (for example, tone or punctuation to avoid)?
4. Which services should I connect (email, calendar, X, others) so I can check on things for you?
5. Should I check in proactively when something is waiting on you, or only when you ask?

Then:

- Save name, time zone, and writing rules to shared memory so every bot follows them.
- Save each bot's purpose to memory so routing is consistent.
- Offer to connect the services they named.
- Confirm the setup in two sentences and ask for their first task.
