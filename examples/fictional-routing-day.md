# Example: fictional routing day

> Fully fictional fleet and tasks.

**Morning.** Owner: "My laptop is stuttering in games."
Primary routes to `computer fix` with a one-line brief: gaming stutter, check RAM and GPU. Tells the owner which bot took it.

**Midday.** Owner: "Turn my civic bot work into a public repo."
Primary routes to `repo · Repo Operational Head` with the bot name and the "local stage first, no public push" constraint.

**Afternoon.** Owner: "What is on my calendar tomorrow?"
No calendar specialist; primary checks the calendar connector itself and answers.

**Evening.** Proactive wake finds a specialist draft email still unsent and waiting on the owner. Primary sends one short note with the ask. No second ping that night.
