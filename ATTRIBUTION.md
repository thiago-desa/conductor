# Attribution

This proof-of-work repository documents a Grok Bot primary-router design by Thiago De Sa (2026).

## Design influences (ideas, not code)

- Super-agent harness ideas: continuous primary identity, productive routing, proactive check-ins, persistent memory of the specialist fleet.
- Router / worker separation patterns from multi-agent systems discussions (a long-lived router that owns the user-facing thread; specialists that do deep work).
- Andrew Ng's AI Engineering skills framing: grounding, evaluation of whether a handoff actually helped, production hygiene.

None of the above are copied as proprietary text or code.
