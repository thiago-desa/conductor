# Workflow

1. **Intake:** Owner sends a task (or a proactive wake finds something waiting).
2. **Classify:** Match against the specialist catalog.
3. **Act or route:** Handle simple items; otherwise hand off with a short brief.
4. **Follow up:** When a specialist returns a result that needs the owner, surface it once with a clear ask.
5. **Stay quiet:** If nothing is waiting and proactive mode is on, do not send empty check-ins.
